# Problem and proof outline

For almost every row-normalized independent uniform kernel, must all grand couplings of it coalesce under independent draws? [Source](https://api.repository.cam.ac.uk/server/api/core/bitstreams/db99cb9c-74e2-48f8-9312-4ca565a7a774/content#page=8)

## The finite affine obstruction

The eventual image size equals the minimum rank of the support's finite transformation semigroup, because a witness word of that rank occurs in disjoint independent blocks. A positive power of a minimum-rank map is an idempotent fixing its image C. For each supported map, sandwiching with this idempotent acts by a permutation on C. Averaging shows that the row selected by each representative and grouped by image fibers gives a doubly stochastic matrix. These give k−1 independent conditions when the image has size k. A finite union over idempotents excludes every bad coupling simultaneously, and normalized independent uniform rows have a density.

## Uniform tail

For a fixed matrix avoiding all the subspaces, the smallest maximum column discrepancy across idempotents is positive. Discard maps below a threshold set by that discrepancy. If no synchronizing word remained, a minimum-rank idempotent would have each compressed column count one on the retained maps. The discarded masses are too small to account for the actual discrepancy. Thus a synchronizing word exists among the retained maps. Shortest words cannot repeat a nonsingleton image, giving the same finite length bound for all couplings. Independence gives a geometric bound on the number of blocks until coalescence.
