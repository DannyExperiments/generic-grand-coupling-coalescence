# Representative rows and idempotent fibers

Extract the ZIP and open index.html locally. Select the map to view and change the probability of the constant map. The two other map weights are equal. Drag sideways or focus the diagram and use the arrow keys to rotate the state markers.

The maps e and f each preserve the representative set {1,2}. They induce the identity and the swap after compression through e. Their equally weighted law has eventual rank two, even though the first coalescing pair can differ. The two compressed column sums are one.

Giving the constant map probability ε changes those sums to 1+ε and 1−ε. For every positive ε in the example, the resulting kernel avoids every rank-two or rank-three idempotent's affine subspace, so every grand coupling coalesces. The explorer tests all seven subspaces using integer arithmetic over a common denominator.

Use Python 3.11 or newer and Pillow 10.1 or newer. Run python3 visualization/render.py from the repository root to rebuild the looping GIF and the offline ZIP.
